# Cómo utilicé la inteligencia artificial

Planteé Factory Guardian a partir de una idea de hackathon. Para esta entrega decidí acotar la propuesta a un chatbot de consultas por reglas, siguiendo la consigna del avance. Mantuve como objetivo comprender el recorrido entre el mensaje, la intención identificada y la respuesta.

Utilicé Codex como apoyo para discutir el alcance, escribir y revisar el código, preparar y ejecutar las pruebas, construir el notebook y redactar la documentación. La evidencia de las conversaciones identifica el entorno utilizado; el notebook se entrega para abrirlo en Google Colab, sin presentar la ejecución local como una ejecución en esa plataforma.

Mi participación estuvo en plantear el proyecto, elegir el alcance de este avance y revisar que la entrega se mantuviera dentro de lo solicitado. Mi responsabilidad es comprender las reglas, explicar por qué una consulta produce determinada respuesta y reconocer sus límites. Los datos ficticios y la guía demostrativa sirven para probar el prototipo, no para describir una planta real.
